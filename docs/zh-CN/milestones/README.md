# Fluxcode 里程碑

本目录用于管理 Fluxcode 的目标、计划、任务拆分和完成记录。

## 目录

- [`targets/`](./targets/runtime-kernel-roadmap-v0.1-v0.5.md)：尚未完成或正在推进的目标、路线图、任务拆分和实现评审。
- [`completed/`](./completed/README.md)：已经完成的里程碑、验收结果和证据索引。

## 维护规则

- 新目标先进入 `targets/`。
- 目标完成后，在 `completed/` 增加完成记录，说明完成范围、验收命令、关键证据和遗留风险。
- 不要把目标文档直接改写成完成记录；目标和完成记录应分开维护。
