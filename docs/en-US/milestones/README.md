# Lattecode Milestones

This directory manages Lattecode targets, plans, task breakdowns, and completed records.

## Directories

- [`targets/`](./targets/runtime-kernel-roadmap-v0.1-v0.5.md): Targets, roadmaps, task breakdowns, and implementation reviews that are not completed or are currently in progress.
- [`completed/`](./completed/README.md): Completed milestones, acceptance results, and evidence indexes.

## Maintenance Rules

- New targets go under `targets/` first.
- When a target is completed, add a completed record under `completed/` with scope, verification commands, key evidence, and residual risks.
- Do not rewrite target documents as completed records; targets and completed records are maintained separately.
