# Fluxcode Proposals

This directory stores design proposals and idea documents that are not yet incorporated into the current formal design set.

## Current Proposals

- No separately indexed proposal documents currently exist. Module documents incorporated into the current design set live under [`../design/modules/`](../design/modules/README.md).

## Maintenance Rules

- Proposal documents must not imply the capability is implemented.
- Before a proposal enters the current formal design set, move or copy it into `design/modules/` or another explicit design category and add acceptance planning under `milestones/targets/`.
- If a proposal is abandoned, mark its status at the top of the document instead of silently deleting it.
